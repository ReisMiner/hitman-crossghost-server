CrossGhost

The All-in-One Versus Multiplayer mode for HITMAN World Of Assassination

Installation

Below are the complete steps you need to follow to install the CrossGhost multiplayer mod to enable GhostMode. Follow them carefully!

Downloads

Download everything listed here in the latest version:

  • ZHMModSDK
  • Simple Mod Framework
  • CrossGhost Client DLL
  • CrossGhost Assets

Setup

  1. Install the ZHMModSDK by copying the contents of the zip inside the Retail folder in the Hitman Installation directory
    • Epic Games default location: C:\Program Files\Epic Games\HITMAN3\
    • Steam default location: C:\Program Files (x86)\Steam\steamapps\common\HITMAN 3
  2. Copy the CrossGhost.dll file inside the mods folder in the Retail directory
  3. Install Simple Mod Framework by creating a folder in the Hitman installation folder called Simple Mod Framework and extracting the zip contents from the SMF download inside this folder.
  4. Run the Mod manager.bat file, go to the enable/disable mods tab, select the GhostMode Assets zip you downloaded and enable and deploy it. Deployment of the mod might take a few minutes.
  5. Run Hitman and open the ZHMModSDK interface with Insert and toggle the CrossGhost Mod on.
  6. Restart the game afterward.

Usage

Right at the start, whenever you enable or disable the mod, you will need to restart the game for the changes to take effect. The mod overwrites the server Hitman is talking to right when the game starts. So a restart is needed to enable or disable the mod for flawless execution.

Following Steps assume the mod is loaded and you see the Ghost Mode button in the main menu.

Hosting a Lobby

  1. Select the Ghost Mode button in the game's main menu.
  2. Select "Choose a map" and choose one.
  3. When in the waiting for players screen, open the ZHMModSDK interface and click "host" in the CrossGhost mod panel (you might need to toggle it at the top bar).
  4. Send the lobby code to your friend and wait for him to join.
  5. Click Ready once you see the 2nd player in the lobby.
  6. Good Luck in your match!

Joining a Lobby

  1. In the main menu, open the ZHMModSDK interface and show the panel of the CrossGhost mod. You might need to toggle it at the top bar.
  2. Enter the code from your friend in the text field.
  3. Click join and once in the lobby press ready.
  4. Good Luck in your match!

Limitations

  • When all targets are killed but no player reached 5 points, the match will softlock and needs to be restarted manually.
  • Enabling or Disabling the CrossGhost mod requires a restart of the game.

About

Hey there, I'm Ramon, a passionate Hitman gamer and software developer!

I decided to develop this expansion of the already existing Hitman Ghost Mode mods as I wanted to play with my friends but they're on steam and I own the game on Epic Games. The existing mod did not allow for such a thing to happen.

As soon as the already existing maps worked (Hawke's Bay, Miami and Santa Fortuna), I started working on making the remaining missions ghost mode compatible.

Methodology & AI Disclosure

As I'm not really familiar with C++ and the inner workings of the game, I decided to use AI to help me create the compatibility layer between steam and epic games and to modify the existing LocalGhost code by grappigegovert.

For the mission modification I created a tool, also using AI, to help me place the targets, crates, and spawns in-game. This was the easiest method for me as I could just move around and hand-place the Objects and NPCs myself without the need to learn much more powerful modding tools.

All content that is in-game for the missions was NOT AI generated. I placed everything for the Ghost Mode missions myself using my tool.

If you find any odd placements or other issues, shoot me a mail or create a post on NexusMods and I'll try to fix the issues.

I disclosed my AI use openly as I think it's important to be transparent about my methods. Below are the repositories on my self-hosted git:

  • CrossGhost Server
  • CrossGhost Assets Mod
  • CrossGhost Client
